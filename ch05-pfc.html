CHAPTER 05

整流與功率因數校正 (PFC)

PFC 讓電源在電網看起來像一顆「純電阻」：電流是乾淨的正弦波、與電壓同相。它本質上就是一個輸入電流被刻意控制成正弦波的 Boost 轉換器（請先讀第 2 章 Boost）。

為什麼需要 PFC

沒有 PFC 會發生什麼

最簡單的 AC→DC 是「整流橋 + 大電容」。電容只有在市電電壓高於電容電壓時（峰值附近一小段時間）才被充電，所以輸入電流是窄而高的脈衝：

功率因數的定義

功率因數 = 實功 / 視在功率。當電壓是正弦波、電流含諧波時：

$$PF = \frac{P}{V_{rms} I_{rms}} = \underbrace{\frac{I_{1,rms}}{I_{rms}}}_{\text{失真因數}}\times\underbrace{\cos\varphi_1}_{\text{位移因數}} = \frac{\cos\varphi_1}{\sqrt{1+THD_i^2}}$$
  • \(I_1\)：基波電流；\(\varphi_1\)：基波電流與電壓的相位差；\(THD_i = \sqrt{\sum_{n\ge2} I_n^2}/I_1\)。
  • 例：THD = 100%（電容輸入型常見）→ 即使 cosφ = 1，PF 也只有 0.707。

PF 差的代價

  • 配電容量浪費：同樣 2000 W，PF = 0.6 時要 3333 VA，斷路器、電線、UPS、發電機都要加大。
  • 諧波污染：三相系統中 3 的倍數次諧波會在中性線相加，中性線電流可能超過相電流而過熱；變壓器額外發熱、電壓波形失真影響其他設備。
  • 法規：IEC 61000-3-2 限制每次諧波電流（資訊設備屬 Class A/D）；資料中心規格通常更嚴（PF ≥ 0.95、iTHD < 5–10%）。

整流橋：最簡單也最浪費的一環

傳統 PFC 前面先有一個二極體整流橋，把交流「翻」成全波脈動直流 \(|v_{in}|\)。任何時刻電流都流經兩顆二極體：

$$P_{bridge} \approx 2\,V_F\,I_{in,avg} = 2\,V_F \cdot \frac{2\sqrt{2}}{\pi} I_{in,rms} \approx 1.8\,V_F\,I_{in,rms}$$
範例 5-1：整流橋損失

\(I_{in,rms}\) = 11.8 A、\(V_F\) ≈ 0.9 V（大電流、高溫）：\(P \approx 1.8 \times 0.9 \times 11.8 = 19\) W，相當於 2000 W 的 ~1% 效率！Titanium 等級做不到 96% 的主要障礙之一。→ 這是「無橋 PFC」誕生的理由。

傳統 Boost PFC

它怎麼讓電流變成正弦波

Boost 的電感電流 = 輸入電流。在一個市電週期內，輸入電壓 \(|v_{in}(t)| = V_{pk}|\sin\omega t|\) 緩慢變化（相對於 65 kHz 開關頻率幾乎是常數），所以每個開關週期都可以視為一個「瞬間 Boost」：

$$d(t) = 1 - \frac{|v_{in}(t)|}{V_o}$$
  • 電壓過零附近：\(d \to 1\)（幾乎全導通才能把一點點電壓升到 400 V）。
  • 電壓峰值附近：\(d\) 最小（例如 230 V 時 \(d = 1 - 325/400 = 0.19\)）。

控制器不直接算 d，而是用電流迴路強迫電感平均電流追隨一個正弦參考 \(i_{ref}(t) \propto |v_{in}(t)|\)，迴路自動調出所需的 d。

三種工作模式

模式功率範圍優點缺點
CCM（連續）> 300 W，伺服器主流峰值電流低、漣波小、EMI 濾波小、固定頻率二極體反向恢復（需 SiC）、硬切換、需要較大電感
CRM / BCM / TCM（臨界）< 300–600 W（交錯可更高）零電流導通、二極體無反向恢復、可做谷底切換、電感小峰值電流 2 倍、頻率變動大、輕載頻率很高
DCM（不連續）< 100–200 W控制最簡單（甚至不需電流迴路）峰值電流很大、導通損失與 EMI 大

平均電流模式控制

三個設計要點

  1. 電流參考： $$i_{ref}(t) = K\cdot\frac{V_c \cdot |v_{in}(t)|}{V_{rms}^2}$$ 為什麼除以 \(V_{rms}^2\)？輸入功率 \(P = V_{rms}I_{rms}\)，而 \(|v_{in}|\) 本身已含 \(V_{rms}\) 一次方，所以 \(i_{ref} \propto V_c/V_{rms}\)，即 \(P \propto V_c\)——電壓迴路輸出直接代表功率，與輸入電壓高低無關，迴路增益不會因 90 V 或 264 V 輸入而改變（稱為「輸入電壓前饋」）。
  2. 電壓迴路必須很慢：Bulk 電容上有 2 倍市電頻率（100/120 Hz）漣波（見第 6 章）。若電壓迴路頻寬太高，\(V_c\) 會跟著漣波上下變化，乘上正弦後讓電流參考出現 3 次諧波 → THD 變差。所以電壓迴路頻寬一般只有 5–20 Hz。代價是負載突變時 Bulk 電壓會有較大過衝/下沖（數位控制常用「非線性快速響應」或漣波消除演算法改善）。
  3. 電流迴路要夠快：要能追隨 100/120 Hz 的整流正弦（含高次諧波），頻寬一般為開關頻率的 1/10 左右（~5–10 kHz）。過零點附近輸入電壓很低、電流斜率受限，是失真主要來源。

CCM Boost PFC 設計計算

輸入電流

$$P_{in} = \frac{P_o}{\eta},\quad I_{in,rms} = \frac{P_{in}}{V_{in,min}\cdot PF},\quad I_{in,pk} = \sqrt{2}\,I_{in,rms}$$

電感

在輸入電壓峰值處，瞬時責任比 \(D = 1 - V_{pk}/V_o\)，漣波 \(\Delta I = V_{pk} D/(L f_s)\)。所以

$$L \ge \frac{V_{pk}\left(1 - \frac{V_{pk}}{V_o}\right)}{\Delta I\, f_s}$$

最壞情況（全範圍）出現在 \(V_{pk} = V_o/2\)：\(\Delta I_{max} = V_o/(4Lf_s)\)。\(\Delta I\) 通常選峰值電流的 20–40%。

開關與二極體電流（含整個市電週期的平均）

$$I_{Q,rms} = I_{in,rms}\sqrt{1 - \frac{8\sqrt{2}\,V_{in}}{3\pi V_o}},\qquad I_{D,avg} = I_o = \frac{P_o}{V_o},\qquad I_{D,rms} = I_{in,rms}\sqrt{\frac{8\sqrt{2}\,V_{in}}{3\pi V_o}}$$
範例 5-2：本講義 2000 W 電源的 PFC（傳統 Boost 版本）
  1. PFC 要輸出的功率：LLC 輸入 ≈ 2000/0.975 ≈ 2050 W，加待機與風扇 → \(P_o\) ≈ 2100 W；效率 98.5% → \(P_{in}\) = 2132 W。
  2. 最低滿載電壓 180 Vac：\(I_{in,rms}\) = 2132/180 = 11.8 A，峰值 16.8 A。（低壓 90 Vac 時降額到 1000 W 輸出，\(I_{in,rms}\) ≈ 12.0 A——兩個設計點電流相近，這正是降額的目的。）
  3. 電感（65 kHz，ΔI = 25% × 16.8 = 4.2 A）：\(V_{pk}\) = 254.6 V，D = 0.363 → \(L = 254.6 \times 0.363/(4.2 \times 65\text{k}) \approx 340\ \mu\)H → 取 350 µH（滿載偏壓下）。全範圍最壞 \(\Delta I_{max} = 400/(4 \times 350\mu \times 65\text{k}) = 4.4\) A。
  4. 電感峰值電流 ≈ 16.8 + 2.2 = 19 A；儲能 \(\tfrac12 L I^2 = 0.5 \times 350\mu \times 19^2 = 63\) mJ → 用來挑磁芯尺寸。
  5. MOSFET RMS（180 Vac）：\(\sqrt{1 - 8\sqrt2 \times 180/(3\pi \times 400)} = \sqrt{1-0.54} = 0.68\) → \(I_{Q,rms}\) = 8.0 A。用 40 mΩ（25 °C）650 V 超接面 MOSFET、高溫 ×1.5 → 導通損失 \(8^2 \times 0.06 = 3.9\) W。
  6. SiC 二極體：\(I_{D,avg}\) = 2100/400 = 5.25 A，RMS 8.7 A → 選 650 V / 16–20 A SiC SBD。

PFC 電感磁芯怎麼選

  • PFC 電感有很大的直流（低頻）偏磁 + 較小的高頻漣波，需要高飽和磁通密度、軟飽和特性 → 常用粉末磁芯：鐵矽鋁（Sendust / Kool Mµ）、High Flux（Fe-Ni）、MPP、鐵矽（Fe-Si）。也可用加氣隙的鐵氧體（體積較大）。
  • 電感隨電流下降（DC bias roll-off）：粉末磁芯在大電流下導磁率下降，例如滿載峰值時只剩 50–60% 的初始電感。設計時要以「滿載偏壓下的電感」為準。這種「軟飽和」反而是好事：輕載時電感大、漣波小、THD 好。
  • 損失：銅損（大部分是 50 Hz 的 RMS 電流 → 粗線）+ 磁芯損失（只由高頻漣波 ΔB 造成，用 Steinmetz 公式估算，見第 13 章）。

交錯式 PFC (Interleaved)

兩個（或三個）Boost 相並聯，開關相位錯開 180°（或 120°）：

  • 每相只承擔一半電流 → 電感、開關各自變小，熱分散。
  • 兩相漣波互相抵消：總輸入漣波頻率變 2 倍、幅度在 D = 0.5 時完全抵消 → EMI 濾波器、輸出電容漣波電流都下降。
  • 輕載時可「相位切除 (phase shedding)」只開一相，提升輕載效率。

無橋 PFC 與圖騰柱 (Totem-Pole) PFC

目標：去掉整流橋的兩顆二極體壓降。演進路線：

架構電流路徑上的元件數特點
傳統 Boost PFC2 顆整流二極體 + 1 顆開關或升壓二極體 = 3簡單成熟、EMI 好處理；整流橋 ~1% 損失

工作原理

市電半週慢臂Boost 主開關同步整流（取代升壓二極體）

每個瞬間電流只經過兩顆 MOSFET（快臂一顆 + 慢臂一顆），沒有任何二極體壓降。

為什麼圖騰柱 CCM 必須用 GaN / SiC？

在 CCM，主開關（如 S2）導通的瞬間，另一顆（S1）的體二極體還在導通電感電流。Si 超接面 MOSFET 的體二極體反向恢復電荷 \(Q_{rr}\) 高達數 µC，會產生巨大的電流尖峰與損失，甚至燒毀元件。GaN HEMT 沒有體二極體（Qrr = 0），SiC MOSFET 的 Qrr 也很小，因此圖騰柱 CCM 直到 GaN/SiC 成熟後才普及。（若用 Si MOSFET，只能做 CRM/TCM 模式，讓電流在每週期反向一點以實現軟切換。）

過零點的挑戰

  • 在市電過零點，慢臂要換邊、快臂主開關與同步整流角色互換。此時快臂的責任比要從接近 1 跳到接近 0，若處理不當會產生電流尖峰（Bulk 電壓經快臂與慢臂的寄生電容灌入）。
  • 做法：過零附近一小段時間先關閉所有開關（死區）、慢臂延遲切換、快臂責任比從 0 開始軟啟動爬升。這些都需要精準的極性偵測與數位控制，所以圖騰柱 PFC 幾乎都用 MCU/DSP 控制（TI C2000、Microchip dsPIC、Infineon XMC 等）。
  • 電流感測：電感電流是交流（雙向），不能用單向分流電阻 → 常用霍爾感測器、雙向分流 + 隔離放大器，或在快臂兩顆開關上各放電流互感器。

數位 PFC 的進階功能

  • 自適應開關頻率 / 相位切除 / 突發模式 (burst)：輕載時降頻或關掉部分相位，提升 10–20% 負載效率。
  • X 電容無功電流補償：輕載時 EMI 的 X 電容電流相對很大，會讓 PF 下降；控制器可把電流參考相位提前補償。
  • 前饋與預測控制：以每週期計算的責任比前饋（\(d_{ff} = 1 - |v_{in}|/V_o\)）減輕電流迴路負擔，降低 THD。
  • Bulk 電壓動態調整：輕載或低壓輸入時降低 Bulk 電壓（例如 380 V），減少開關損失；但要確保 LLC 增益範圍足夠。
  • 交流掉電偵測與 Hold-up 管理：偵測到 AC 消失立刻停止 PFC、通知二次側。

自我檢測

Q1. 電流相位與電壓完全相同，但波形是方波（THD ≈ 48%），PF 是多少？

\(PF = 1/\sqrt{1+0.48^2} \approx 0.90\)（方波基波佔 RMS 的 \(2\sqrt2/\pi \approx 0.90\)）。

Q2. 為什麼 PFC 輸出要選 ~400 V？可以選 300 V 嗎？

Boost 輸出必須高於最高輸入峰值（264 × √2 = 373 V）加裕量，否則在高壓輸入時無法控制電流（二極體直接導通）。400 V 也讓 650 V 元件有足夠耐壓裕量，並讓 Bulk 儲能（∝ V²）較高。

Q3. 若把電壓迴路頻寬從 10 Hz 提高到 100 Hz，會發生什麼？

100/120 Hz 漣波進入電流參考，參考波形被調變而失真（主要是 3 次諧波），THD 與 PF 變差；但負載暫態時 Bulk 電壓變動較小。這是典型取捨。

Q4. 圖騰柱 PFC 中，慢臂為什麼可以用便宜的 Si MOSFET？

慢臂只在市電頻率（50/60 Hz）切換，而且是在電壓過零時切換，切換損失幾乎為零，只需要低導通電阻；其體二極體反向恢復的問題在這麼低的頻率、零電壓下切換時不顯著。
