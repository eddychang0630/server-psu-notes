CHAPTER 07 · 本講義重點章

LLC 諧振轉換器（主 DC-DC）

LLC 把 400 V 轉成隔離的 12 V，是伺服器電源效率的心臟。它不靠改變責任比，而是靠改變開關頻率來調整輸出；並利用 L-L-C 三個元件的諧振，讓一次側開關「零電壓導通 (ZVS)」、二次側整流「零電流關斷 (ZCS)」。這一章從直覺 → 工作階段 → 波形 → 數學 (FHA) → 完整設計步驟 → 變壓器 → 控制，一次講清楚。

為什麼主 DC-DC 選 LLC

回顧第 2 章：硬切換的損失 \(\propto V \cdot I \cdot f_s\)，400 V 級電路在數百 kHz 時切換損失非常可觀。LLC 的優勢：

  • 一次側 ZVS：開關導通前，電壓已經被諧振電流降到 0 → 導通損失（\(\tfrac12 C_{oss}V^2\)）消失，且 dv/dt 平緩、EMI 低。
  • 二次側 ZCS（在 \(f_s \le f_r\) 時）：整流器電流自然降到 0 才關斷 → 沒有反向恢復損失、沒有電壓尖峰 → 可用低耐壓、低 \(R_{DS(on)}\) 的同步整流 MOSFET。
  • 沒有輸出電感：輸出直接接電容，二次側整流器的電壓應力被箝位在 2Vo（中心抽頭），對低壓大電流特別有利。
  • 可以整合磁性元件：Lr 可以用變壓器漏感、Lm 就是變壓器激磁電感，一顆變壓器包辦。
  • 前級有 PFC 穩住 400 V：LLC 不需要很寬的輸入範圍，正常時可以一直工作在最有效率的諧振點附近。

兩個諧振頻率

LLC 的「三個元件」形成兩個諧振頻率：

$$f_r = \frac{1}{2\pi\sqrt{L_r C_r}}\qquad\qquad f_m = \frac{1}{2\pi\sqrt{(L_r+L_m)C_r}} = \frac{f_r}{\sqrt{1+L_n}},\quad L_n = \frac{L_m}{L_r}$$
  • \(f_r\)（串聯諧振頻率）：二次側整流器導通時，Lm 被輸出電壓「箝位」（兩端電壓固定為 ±nVo），不參與諧振，只有 Lr 和 Cr 諧振。
  • \(f_m\)：二次側整流器都不導通時（輕載或 fs < fr 的某段時間），Lm 與 Lr 串聯一起和 Cr 諧振。

LLC 正常工作在 \(f_m < f_s\)，最佳效率點在 \(f_s \approx f_r\)。

工作原理：一個開關週期發生什麼事

以 \(f_s = f_r\)（諧振點）為例，把半個週期拆成幾個階段（另外半週期完全對稱）：

  1. 死區 → Q1 ZVS 導通：Q2 剛關斷，此時諧振電流 \(i_{Lr}\) 為負（從 A 點流出方向的反向），它把 A 點的寄生電容（Q1、Q2 的 Coss）充放電，使 A 點電壓上升到 Vin，Q1 的體二極體先導通。這時 Q1 的 \(V_{DS}\) ≈ 0，再送閘極訊號 → 零電壓導通。
  2. 能量傳遞期（Q1 導通）：A 點 = Vin，Lr-Cr 以 \(f_r\) 諧振，\(i_{Lr}\) 是一段正弦波。變壓器一次側電壓被二次側箝位在 \(+nV_o\)，所以 Lm 上電壓固定，\(i_{Lm}\) 線性上升（三角波）。兩者的差 \(i_{Lr} - i_{Lm}\) 經變壓器傳到二次側，SR1 導通，二次側電流也是半個正弦。
  3. 電流交會 → SR ZCS 關斷：剛好半個諧振週期結束時（fs = fr），\(i_{Lr}\) 下降到與 \(i_{Lm}\) 相等，二次側電流自然降到 0，SR1 零電流關斷，沒有反向恢復。
  4. Q1 關斷 → 死區：關斷瞬間的電流 = 磁化電流峰值 \(I_{m,pk}\)（不是負載電流！所以關斷損失也很小）。這個電流把 A 點電壓拉向 0，讓 Q2 下一次 ZVS 導通。

低於諧振 (\(f_m < f_s < f_r\))：升壓區

開關週期比諧振週期長：諧振的半個正弦結束後，\(i_{Lr}\) 已經等於 \(i_{Lm}\)、二次側電流歸零，但開關還沒切換。此時 SR 都關閉，Lm 不再被箝位而加入諧振（Lr+Lm 與 Cr，頻率 \(f_m\) 很低），所以 \(i_{Lr}\) 在這段時間幾乎持平。

高於諧振 (\(f_s > f_r\))：降壓區

半個諧振週期還沒結束，開關就切換了：二次側電流在還很大的時候被強制換向，SR 失去 ZCS（需要精確的 SR 關斷控制）。一次側仍然有 ZVS。增益 < 1，用於輸入電壓偏高或輕載。

🔬 自己動手：LLC 時域模擬器

拖動滑桿觀察：(1) fs/fr 從 0.6 調到 1.5，二次側電流形狀怎麼變；(2) 把 Q 加大（重載），在 fs/fr = 0.6 時是否仍有 ZVS；(3) 把 Ln 從 3 調到 10，磁化電流（橘）大小變化。

ZVS 的條件（最重要的設計約束）

ZVS 需要兩個條件同時成立：

  1. 工作在感性區：諧振槽的輸入阻抗必須是電感性（電流落後電壓），開關關斷時電流方向才正確。在增益曲線上就是峰值的右側。若進入峰值左側的容性區，電流領先電壓，開關會在體二極體仍導通時被硬導通 → 體二極體反向恢復 → 巨大電流尖峰，常常直接燒毀 MOSFET。
  2. 能量足夠：死區時間內，電流要能把橋臂節點的電容（上下兩顆 Coss 並聯 + 變壓器寄生電容）從 0 完全充到 Vin： $$I_{m,pk}\cdot t_{dead} \ \ge\ C_{node}\,V_{in},\qquad C_{node} \approx 2C_{oss(tr)} + C_{stray}$$ 在 \(f_s \approx f_r\) 時，關斷電流 ≈ 磁化電流峰值： $$I_{m,pk} = \frac{n V_o}{4 L_m f_s}$$ 所以 Lm 有上限： $$L_m \le \frac{n V_o\, t_{dead}}{4 f_s\, C_{node}\, V_{in}}\quad\xrightarrow{\text{全橋 } nV_o\approx V_{in}}\quad L_m \le \frac{t_{dead}}{4 f_s\, C_{node}}$$
Lm 的兩難

Lm 小：磁化電流大 → ZVS 容易、增益峰值高（Hold-up 好）；但磁化電流是「只在一次側來回、不傳到輸出」的循環電流，會增加導通損失與關斷損失，輕載效率差。
Lm 大：循環電流小、效率高；但 ZVS 變難、增益範圍變窄。
設計就是在這兩者之間找平衡——而 Ln = Lm/Lr 就是這個平衡的主要旋鈕。

FHA 分析：推導增益公式

基波近似法 (First Harmonic Approximation, FHA)：諧振槽像一個帶通濾波器，在 \(f_s\) 附近只讓基波通過，所以只看方波的基波就能近似分析。

Step 1：輸入方波 → 基波

全橋 ±Vin 方波的基波振幅：

$$v_{AB,1}(t) = \frac{4V_{in}}{\pi}\sin(\omega_s t)$$

Step 2：整流器 + 負載 → 等效交流電阻 \(R_{ac}\)

二次側整流器輸入端電壓是 ±Vo 方波（基波振幅 \(4V_o/\pi\)），電流是正弦（整流後平均 = Io，所以峰值 \(\pi I_o/2\)）。兩者同相，等效為電阻：

$$R_{ac,sec} = \frac{4V_o/\pi}{\pi I_o/2} = \frac{8}{\pi^2}R_o,\qquad R_{ac} = n^2 R_{ac,sec} = \frac{8n^2}{\pi^2}R_o,\quad R_o = \frac{V_o}{I_o}$$

Step 3：分壓 → 增益

$$M = \left|\frac{v_{o,1}}{v_{AB,1}}\right| = \left|\frac{j\omega L_m \parallel R_{ac}}{j\omega L_m \parallel R_{ac} + j\omega L_r + \frac{1}{j\omega C_r}}\right|$$

定義三個無因次參數：

$$f_n = \frac{f_s}{f_r},\qquad L_n = \frac{L_m}{L_r},\qquad Q = \frac{\sqrt{L_r/C_r}}{R_{ac}} = \frac{Z_r}{R_{ac}}$$

整理後得到最重要的 LLC 公式：

$$\boxed{M(f_n,L_n,Q) = \frac{L_n f_n^2}{\sqrt{\left[(L_n+1)f_n^2 - 1\right]^2 + \left[(f_n^2-1)\,f_n\,Q\,L_n\right]^2}}}$$

且全橋時 \(M = nV_o/V_{in}\)（半橋 \(M = 2nV_o/V_{in}\)）。

從公式讀出的重要性質

  • \(f_n = 1\) 時 \(M = 1\)，與 Q 無關：代入 \(f_n=1\)，分母第二項為 0，\(M = L_n/L_n = 1\)。這就是「負載無關點」——不管輕載重載，在諧振點的增益都是 1。所以設計時讓額定輸入電壓剛好對應 fs = fr（由匝比保證），正常工作就在最佳點。
  • \(f_n \to \infty\)（且 Q 很小，輕載）時 \(M \to L_n/(L_n+1)\)：例如 Ln = 5 時最低只能降到 0.833。輕載時若需要更低增益（輸入過高、無載），光提高頻率做不到 → 需要突發模式 (burst mode)。
  • Q 越大（負載越重），增益峰值越低、峰值位置越接近 \(f_r\)。
  • Ln 越小，增益峰值越高、曲線越陡（較小的頻率變化就能改變增益）。
FHA 的限制

FHA 在 \(f_s \approx f_r\) 附近很準；離諧振越遠（特別是 \(f_s \ll f_r\) 的升壓區、重載）誤差越大：實際增益曲線的形狀、峰值大小與位置都會和 FHA 不同（上方模擬器同時顯示「時域增益」與「FHA 增益」，你可以把 fs/fr 調到 0.5–0.7 或 1.5 親眼比較）。所以 FHA 只用來決定初始參數，正式設計一定要用時域模擬（SIMPLIS、PSIM、LTspice）確認實際頻率範圍與增益峰值。

增益曲線：互動圖

讀圖要點：

  • 右側 (\(f_n > 1\))：降壓區，增益 < 1，曲線對 Q 不敏感。
  • \(f_n\) 介於峰值與 1 之間：升壓區，仍在感性區（ZVS 成立）。
  • 峰值左側（紅色區）：容性區，禁止進入。控制器必須限制最低頻率，並有容性模式保護。
  • 設計目標：在最低輸入電壓（Hold-up 末端）、最大負載（含過載裕量）時，所需增益 \(M_{max}\) 仍低於該 Q 的峰值，並留 10–20% 裕量。

LLC 完整設計步驟（含範例）

規格（延續本講義）：Vin 額定 390 V、範圍 300–410 V（300 V 為 Hold-up 末端）、Vo = 12.2 V、Po = 2000 W、全橋 LLC、中心抽頭 SR（壓降 ~0.1 V）。

  1. 選諧振頻率 \(f_r\)

    頻率越高，磁性元件與電容越小；但開關的驅動損失、關斷損失、磁芯損失、繞組交流電阻（集膚/鄰近效應）、SR 控制時序的難度都會增加。Si MOSFET 方案常見 100–200 kHz；SiC/GaN 方案 250 kHz – 1 MHz。範例取 \(f_r\) = 250 kHz。

  2. 決定匝比 n（讓額定輸入落在諧振點） $$n = \frac{N_p}{N_s} = \frac{V_{in,nom}}{V_o + V_{SR}} = \frac{390}{12.2 + 0.1} = 31.7 \;\rightarrow\; n = 32$$

    （半橋則為 \(V_{in}/2\) 除以 \(V_o\)，約 16。）實際上 \(N_s\) = 1 匝時 \(N_p\) = 32 匝；2 kW 等級常用兩顆變壓器組成「矩陣變壓器」：一次側串聯（各 16 匝）、二次側並聯，分散大電流。

  3. 計算增益範圍 $$M_{max} = \frac{n(V_o+V_{SR})}{V_{in,min}} = \frac{32 \times 12.3}{300} = 1.31,\qquad M_{min} = \frac{32 \times 12.3}{410} = 0.96$$

    若輸出電壓可透過 PMBus 調整（例如 12.0–12.6 V），要把調整範圍也算進去。

  4. 計算等效負載 Rac $$R_o = \frac{V_o^2}{P_o} = \frac{12.2^2}{2000} = 0.0744\ \Omega,\qquad R_{ac} = \frac{8n^2}{\pi^2}R_o = \frac{8 \times 1024}{9.87}\times 0.0744 = 61.8\ \Omega$$
  5. 選擇 Ln 與 Q

    用上面的增益圖：Ln = 5、Q = 0.35 時峰值增益 ≈ 1.52 > 1.31 × 1.1 = 1.44 ✅。檢查過載：110% 負載時 Q 變為 0.385，峰值約 1.45，仍高於 1.31（裕量較小）。常見經驗：Ln = 3–8；Q 在 0.3–0.5。

    選擇好處代價
    Ln 小（3–4）峰值增益高、頻率範圍窄、Hold-up 好Lm 小 → 循環電流大、輕載效率差
    Ln 大（7–10）循環電流小、效率高需要很寬頻率範圍、峰值增益低
    Q 小峰值高Zr 小 → Cr 大、Lr 小；Cr 電流與電壓應力仍要檢查
    Q 大Lr 大、Cr 小峰值低、可能無法滿足 Mmax
  6. 計算諧振元件 $$Z_r = Q\cdot R_{ac} = 0.35 \times 61.8 = 21.6\ \Omega$$ $$C_r = \frac{1}{2\pi f_r Z_r} = \frac{1}{2\pi \times 250\text{k} \times 21.6} = 29.5\ \text{nF}$$ $$L_r = \frac{Z_r}{2\pi f_r} = \frac{21.6}{2\pi \times 250\text{k}} = 13.8\ \mu\text{H},\qquad L_m = L_n L_r = 69\ \mu\text{H}$$

    選標準值（例如 Cr = 30 nF，用多顆 C0G/NP0 陶瓷或 PP 薄膜並聯），再反算 Lr 讓 fr 不變。

  7. 檢查 ZVS $$I_{m,pk} = \frac{nV_o'}{4L_m f_r} = \frac{32 \times 12.3}{4 \times 69\mu \times 250\text{k}} = 5.7\ \text{A}$$

    死區 80 ns：每顆開關容許 \(C_{oss(tr)} \le I_{m,pk} t_{dead}/(2V_{in}) = 5.7 \times 80\text{n}/780 \approx 585\) pF。650 V GaN/SiC 或超接面 MOSFET 的 Coss(tr) 一般數百 pF 以內 ✅。也要在最高頻率（輕載、高輸入）時檢查，因為頻率越高 \(I_{m,pk}\) 越小。

  8. 計算電流與應力

    一次側 RMS（諧振點）：負載反射部分（正弦） \(I_{load} = \dfrac{\pi I_o}{2\sqrt2\, n}\)、磁化部分（三角） \(I_{m,rms} = I_{m,pk}/\sqrt3\)：

    $$I_{p,rms} = \sqrt{\left(\frac{\pi \times 164}{2\sqrt2 \times 32}\right)^2 + \left(\frac{5.7}{\sqrt3}\right)^2} = \sqrt{5.69^2 + 3.29^2} = 6.6\ \text{A}$$

    Cr 峰值電壓（全橋無直流偏壓）：\(V_{Cr,pk} \approx I_{p,pk}\cdot Z_r\cdot\frac{f_r}{f_s}\)，取 \(I_{p,pk} \approx \sqrt2 \times 6.6 = 9.3\) A → \(\approx 200\) V；在最低頻率、過載時會更高 → 選 630 V 以上額定。

    二次側每顆 SR（中心抽頭，各導通半週正弦）：\(I_{SR,rms} = \dfrac{\pi}{4}I_o = 129\) A（!）、電壓應力 \(2V_o\) ≈ 24.4 V + 振鈴 → 選 40 V MOSFET，多顆並聯（第 8 章）。

  9. 決定頻率範圍

    由增益曲線反查：滿載 \(M_{max}\) = 1.31 時 \(f_n \approx 0.62\) → \(f_{min} \approx 155\) kHz；輕載 \(M_{min}\) = 0.96 時（Q→0）\(f_n \approx 1.12\) → \(f_{max} \approx 280\) kHz。控制器的頻率夾限設在 \(f_{min}\) 以下一點（但不進入容性區）與軟啟動起始頻率（例如 2–3 fr）。

  10. 變壓器與 Lr 設計（下一節）→ 時域模擬驗證 → 實測迭代。

變壓器設計

磁通密度與一次側匝數

一次側電壓近似 ±\(nV_o\) 方波，半週期的伏秒決定磁通擺幅：

$$\Delta B = \frac{nV_o \cdot \frac{T_s}{2}}{N_p A_e}\quad\Rightarrow\quad B_{pk} = \frac{nV_o}{4\,N_p\,A_e\,f_s}$$

最壞情況在最低頻率（\(f_{min}\)）。高頻鐵氧體（如 TDK PC95、Ferroxcube 3C95/3C97 類材料）在 100–300 kHz 時，為了控制磁芯損失，\(B_{pk}\) 常選 0.05–0.15 T。

範例 7-1：檢查磁通

若用 PQ50/50 類磁芯（\(A_e\) ≈ 328 mm²）、\(N_p\) = 32：\(B_{pk} = 390/(4 \times 32 \times 328\mu \times 155\text{k}) \approx 0.06\) T，低磁通 → 低鐵損。若改用矩陣變壓器（兩顆各 16 匝、各承受一半電壓），每顆的 \(B_{pk}\) 同樣約 0.06 T，但每顆尺寸可以更小。

激磁電感 Lm 與氣隙

$$L_m \approx \frac{\mu_0 N_p^2 A_e}{l_g}\quad\Rightarrow\quad l_g \approx \frac{\mu_0 N_p^2 A_e}{L_m}$$

小 Lm（數十 µH）、多匝數時，算出的氣隙可能達數 mm。大氣隙會產生嚴重的邊緣磁通 (fringing)，在附近的繞組中感應渦流發熱。對策：分散氣隙（多段小氣隙）、繞組避開氣隙位置、減少匝數（矩陣變壓器）。

繞組：集膚效應與鄰近效應

  • 集膚深度（銅，室溫）：\(\delta \approx \dfrac{66}{\sqrt{f}}\ \text{mm}\)，250 kHz 時 δ ≈ 0.13 mm。比 2δ 粗的實心導線，中心幾乎沒有電流 → 一次側用利茲線 (Litz wire)（多股細絕緣線絞合）。
  • 二次側（1 匝、上百安培）：用銅箔或 PCB 平面繞組（planar），並和一次側交錯繞 (interleaving) 以降低鄰近效應。
  • 平面變壓器 (Planar)：繞組做在多層 PCB 上，高度低、寄生參數一致、散熱好，非常適合 CRPS 的扁平外型與 GaN 高頻設計。

Lr：整合漏感還是獨立電感？

整合在變壓器（漏感）獨立諧振電感

LLC 控制

  • 頻率調變：回授誤差經補償器輸出 → VCO（壓控振盪器）或數位計數器決定開關週期。輸出電壓太低 → 降低頻率（增益上升）。
  • 軟啟動：從高頻（例如 2–3 倍 fr，增益很低）開始，逐步降低頻率，避免輸出電容充電時的大電流與容性區。
  • 輕載 / 無載：突發模式 (Burst mode)：因為增益下限 \(L_n/(L_n+1)\)，加上 SR 與變壓器寄生電容在高頻時反而讓增益上升，輕載時改成「打一串脈衝、停一段時間」，降低開關次數，提升輕載效率並維持穩壓。
  • 過流保護：量測一次側電流（電流互感器）或 Cr 電壓（Cr 電壓正比於電荷 = 電流積分）。短路時提高頻率限流，並在一定時間後關機。
  • 容性模式保護：偵測開關切換瞬間的電流極性，一旦接近容性區立即提高頻率或關閉。
  • 先進控制法：例如混合式遲滯控制（以 Cr 電壓與電流資訊決定切換時刻，暫態響應更快）、時間平移控制等。數位控制常在二次側 MCU 中實作，並同時處理 SR 驅動時序（第 8 章）與 PMBus（第 11 章）。

另一個選擇：相移全橋 (PSFB)

Phase-Shifted Full Bridge 是「Buck 加變壓器」家族：四顆開關都以 50% 責任比切換，靠兩臂之間的相位差決定有效責任比（重疊時才對變壓器施加電壓）。利用漏感（或外加諧振電感）與開關電容實現 ZVS；二次側有輸出電感（常用電流倍增器 current-doubler）。

常見設計陷阱

  • 只用 FHA 就定案：FHA 在升壓區、重載時誤差明顯，實際的頻率範圍與增益峰值必須以時域模擬與實測確認，並保留裕量。
  • 忽略寄生電容：變壓器繞組電容、SR 的 Coss 反射到一次側，會讓高頻時增益上升（無法降壓），輕載失控。
  • Cr 選錯材質：Cr 承受大交流電流與高 dv/dt，必須用低損失的 C0G 陶瓷或 PP 薄膜；X7R 陶瓷電容值隨電壓變化（且損耗大），會讓 fr 漂移。
  • SR 誤動作：SR 太早關 → 走體二極體（損失大）；太晚關 → 電流倒灌、甚至讓一次側失去 ZVS（第 8 章）。
  • 啟動與保護時進入容性區：短路、啟動、Hold-up 末端最容易出事。

自我檢測

Q1. 為什麼 LLC 在 fs = fr 時增益與負載無關？

在 fr，Lr 與 Cr 的阻抗大小相等、相位相反，串聯總阻抗為 0，所以輸入基波電壓完全落在 Lm // Rac 上，不論 Rac 多大多小，分壓比都是 1。

Q2. 全橋 LLC，Vin = 400 V，Vo = 54 V，諧振點匝比是多少？若改半橋呢？

全橋 n ≈ 400/54 = 7.4；半橋 n ≈ 200/54 = 3.7（忽略整流壓降）。

Q3. 為什麼 LLC 關斷損失也很小？

關斷瞬間的電流只是磁化電流峰值（範例中 5.7 A），而非負載電流反射的峰值；再加上開關兩端可並聯小電容讓電壓緩升（ZVS 關斷），關斷損失很低。

Q4. 在增益曲線峰值左側工作會怎樣？

諧振槽變成容性，電流領先電壓。開關關斷時電流方向錯誤，下一顆開關會在對管體二極體仍導通時硬導通，造成體二極體反向恢復電流尖峰、失去 ZVS、嚴重時直通燒毀。

Q5. Ln = 6 時，無載能把增益降到多低？若需要 0.8 怎麼辦？

\(M_{min} \to 6/7 = 0.857\)；需要 0.8 時無法單靠頻率達成，必須使用突發模式（或改變調變方式，如全橋切成半橋模式）。
